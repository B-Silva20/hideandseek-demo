# 《虚构推理》

由玩家导入 TXT 案件材料、配置兼容 OpenAI 的模型服务后进行审讯推理的本地网页游戏。案件原文只在解析时使用；审讯阶段以结构化线索、证物、人物状态和有限上下文推进。

## 功能

- 粘贴文本或导入 UTF-8 / GB18030 TXT，自动识别案件标题。
- 超大文本分段解析，显示真实进度并可取消；上限为 100 万字符、16 MB。
- 困难、普通、简单与练手四档行动点设置。
- 嫌疑人、证物栏、可用话术、证词矛盾板和逮捕结局。
- P5R 风格的黑、暖白、红色纸片视觉，并适配不同缩放比例。
- 本地自动存档；案件原文、存档和模型密钥均不提交到仓库。

## 本地运行

需要 Node.js 22.12 或更新版本。

```powershell
Copy-Item .env.example .env
npm install
npm run dev
```

打开 <http://127.0.0.1:5173>。在网页“API 配置”中填写兼容 OpenAI 的模型地址、模型名和 API Key；密钥仅保存在当前后端进程。

```powershell
npm test
npm run lint
npm run build
```

## Windows 发布包

仓库根目录的 `虚构推理.zip` 是可直接分发的 Windows 包。解压后双击 `虚构推理.exe` 即可启动；它自带 Node 运行时，关闭游戏浏览器窗口会结束本次后台服务。

发布包不包含 `.env`、玩家存档、案件原文或浏览器缓存。首次运行后，玩家在网页内自行配置模型服务并导入案件。
